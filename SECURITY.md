# Security policy

## Report a vulnerability

Email **ops@geniffy.com** with what you found and how to reproduce it. Please don't open a public issue,
pull request or discussion about it.

We confirm that we have your report, keep you updated while we work on it, and tell you when it is fixed.
If you would like to be credited when the fix is described, say so in your email.

## In scope

- The Geniffy API at `api.geniffy.com`, including the MCP server at `api.geniffy.com/mcp` and its sign-in
- The apps at `geniffy.com`
- The docs at `docs.geniffy.com`
- The SDKs in this organization, published as `geniffy` on PyPI and npm

## Please don't

- Access, change or delete data that isn't yours
- Run tests that slow the service down for other people, such as load tests or spam
- Use social engineering against our team or our users

Reports made in good faith within these limits are welcome help.
