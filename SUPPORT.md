# Getting help

- **How do I...?** Start at [docs.geniffy.com](https://docs.geniffy.com). Every page has Ask AI, which
  answers from the docs and links the page it used.
- **A bug in an SDK or an example:** open an issue in that repository.
- **Your account or your keys:** email ops@geniffy.com.
- **A security problem:** follow the [security policy](SECURITY.md).
